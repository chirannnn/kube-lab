# my kubernetes configuration

This repository contains my Kubernetes configurations and infrastructure experiments as I learn how to build and operate production-oriented Kubernetes environments.

It covers Kubernetes workloads, networking, security, configuration management, and deployment practices, with a focus on understanding how these components work together in a real-world environment.

The configurations and experiments are based on hands-on practice and learning from [cetanu/kube-stuff](https://github.com/cetanu/kube-stuff).
